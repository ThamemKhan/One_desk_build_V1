### 1.1 Data domains
Enterprise data is organised into domains. Each domain has a named Data Custodian
accountable for classification, retention and access.

### 2.2 Delegation of operational approval
For routine access requests, the Data Custodian may delegate approval to the Application
Owner of the system through which the data is accessed. NOTE: this clause was withdrawn
by POL-SEC-204 version 3.1 effective 2026-04-01 and is retained for historical reference only.

### 2.5 Classification
Data is classified as Public, Internal, Confidential or Restricted. Production customer
data is classified Restricted by default.

### 4.1 Retention
Access grant records are retained for seven years for audit purposes.
