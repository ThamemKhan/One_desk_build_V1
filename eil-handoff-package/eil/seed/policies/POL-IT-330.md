### 1.1 Service ownership
Every enterprise application has a named Application Owner accountable for its
availability, cost and access administration.

### 3.4 Access request intake
Requests for access to applications owned by IT Platform must be raised and validated
through Human Resources before technical provisioning is scheduled. NOTE: superseded in
part by POL-SEC-204 clause 4.3 with effect from 2026-04-01.

### 3.6 Provisioning
Technical provisioning is performed by IT Platform only on receipt of a valid approval
from the authority named in the governing policy.

### 5.1 Software licences
Requests for commercial software licences are approved by IT Platform, subject to the
expenditure thresholds set out in the Expenditure Authorisation Policy.

### 5.4 Standard catalogue
Software on the standard catalogue may be provisioned without additional review where
the annualised value falls below the Finance high-value threshold.
